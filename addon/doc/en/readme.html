Simple Link Opener

Author: Muteb Almarri

Opens the links in the clipboard in your default browser with one gesture. There is no question about which browser to use.

Setting up the gesture

The command has no gesture until you assign one. Open the NVDA menu, then Preferences, then Input gestures. Find the "Simple Link Opener" category, choose the command that starts with "Pressed once, says the link in the clipboard", and press Add.

Pressing the gesture once

  • One link in the clipboard: NVDA says the link.
  • Several links: NVDA says how many, for example "3 links".
  • No link: NVDA says "No link in clipboard".

Pressing the gesture twice

  • One link in the clipboard: it opens in your default browser, and NVDA says "Opening link".
  • Several links: a list of the links appears. Press Enter on a link to open that one. Or tab to the "Open N links" button, where N is the number of links, to open all of them. NVDA says, for example, "Opening 3 links". Press Escape to close the list without opening anything.
  • No link: NVDA says "No link in clipboard".

Settings

Open the NVDA menu, then Preferences, then Settings, then the "Simple Link Opener" category. A group of checkboxes chooses which kinds of links are opened:

  • Links starting with http:// (checked by default)
  • Links starting with https:// (checked by default)
  • Links starting with www., such as www.example.com (not checked by default). These links are opened with https:// added in front.
  • TeamTalk links starting with tt://, such as tt://example.com?tcpport=10333 (not checked by default). The TeamTalk client opens these links.

The add-on does nothing on secure screens, such as the Windows sign-in screen.
